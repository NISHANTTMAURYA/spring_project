How it works:
  1. Take a photo of your handwritten or typed todo list
  2. Upload the image using the form below
  3. Gemini AI will analyze the image and extract tasks
  4. Extracted tasks will be added to your todo list

Troubleshooting Tips:
  1. Ensure you have a valid Gemini API key configured in application.properties
  2. Check if the Gemini service is enabled (google.ai.enabled=true)
  3. Verify the correct model URL is being used
  4. Try using a clear, well-lit image of your todo list
  5. Images should be in a supported format (JPEG, PNG) and less than 10MB
